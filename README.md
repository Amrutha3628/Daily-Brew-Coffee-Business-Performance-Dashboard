☕ Daily Brew Coffee Business Performance

📌 Project Overview

The Daily Brew Coffee Business Performance project focuses on analyzing coffee business data to understand sales performance, product performance, customer purchasing patterns, and overall business trends.

The project was developed using Microsoft Excel and Power BI, covering the complete data analytics workflow from data cleaning and transformation to analysis, visualization, and business insight generation.

⸻

🎯 Business Objective

The main objectives of this project are to:

* Analyze overall coffee business performance
* Identify sales and profit trends
* Understand product and category performance
* Analyze customer purchasing patterns
* Identify key business performance indicators
* Discover meaningful trends and patterns
* Generate actionable insights to support better business decisions

📊 Dataset

The dataset contains coffee business transaction data used to analyze sales, products, customers, quantities, revenue, profit, and other business performance metrics.

The data was cleaned and transformed before performing the analysis.

⸻

🧹 Data Cleaning & Transformation

The data preparation process included:

* Removing duplicate records
* Handling missing values
* Standardizing data formats
* Cleaning inconsistent values
* Transforming data into an analysis-ready format
* Using VLOOKUP to combine relevant information
* Validating the cleaned dataset before analysis
